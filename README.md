# 🏝️ Treasure Island Game

A simple *Python text adventure game* where the player chooses doors and boxes to find the treasure.

---

## 🎮 How to Play
1. Run the main.py file.
2. Follow the instructions on the screen.
3. Choose wisely to find the treasure!

---

## 🧠 What I Learned
- Using *if / elif / else* statements.
- Working with *input()* and *print()*.
- Understanding how to build simple text-based games.

---

## 💻 Example Output

Welcome to Treasure Island. Your mission is to find the treasure. You reach a cross road. Where do you want to go? Left or Right?
